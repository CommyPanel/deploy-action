# Security

If you find a security problem in this action, please do not open a public issue. Report it privately through
GitHub's "Report a vulnerability" button on this repository (Security tab). You will get an answer, and a fix for
a confirmed problem is released before the details are made public.

This action handles a deployment token, so the things that matter most are: inputs reaching a shell, what is
installed and how it is checked, what ends up in the log, and which events may run it. Reports about any of those
are especially welcome.

Problems in `commy` or in the CommyPanel server belong in their own repositories.
